The kernel is the organism. The model is a gland.

Prime Agent is an RLM with the mind in TypeScript and the hands in IPython. The inversion is not “XML instead of tools.” It is: move the loop, the attention function, the goal, and the farm into the image the hands already live in.

Prime’s own invariant, from rlm-runtime.md: “The Python side does not call providers or implement an agent loop.” That sentence is the thing you break.

Reloadable means: frozen names are re-injected, heap names survive, harness JSON is mtime-synced, runtime identity is a hash of rlm/*.py. That order is load-bearing. Invert the loop; do not invert this boot sequence.

Three ways to fork a brain — do not collapse these

L0 think()

Same heap, one complete

  • Temporary view overlay
  • Paper-RLM recursion
  • Summarize a pin, extract, classify
  • Cheap. No new process
L1 activity()

Same kernel, own cursor

  • Own view + goal + mailbox
  • Cooperative — IPython is serial
  • Interleaved attention, not speed
  • This is “being several people”
L2 kernel()

Forkserver child

  • Isolated heap, own step()
  • Prime’s rlm() — keep it
  • Mailbox / files for fan-in
  • Only this is real parallelism
IPython runs one cell at a time. Prime already says this. A “subagent farm” that is all L1 is a coroutine cosplay. Parallel work is L2. Thinking-over-a-blob is L0. Goal mode is an L1 activity that owns an L2 farm.

Goal + farm is one metabolism, not two features

# frozen scheduler — agent cannot rewrite priority
on tick:
  user message        # always first
  child / mailbox     # farm results
  goal.wake()         # only if idle and budget remains
  heartbeat / clock   # lowest
  else sleep

# a goal is not a host-injected paragraph. it is:
Goal(
  objective, budget,
  plan,            # agent-writable
  farm,            # optional L2 pool
  pins,            # always in view header
  wake,            # on_idle | on_message | every_5m | on_child_done
)
1 User talk — the creature is interrupted, not replaced
2 Mailbox — a worker finished; fold, don’t restart the goal from scratch
3 Goal wake — continue only if budget says so; hint is tiny, objective lives on the heap
4 Clock — heartbeats. If nothing is due, the process sleeps. Alive ≠ hot loop

What not to put in the image

keep in host
  • Provider credentials and complete()
  • Daemon attach / leases / crash recovery
  • JSONL transcript (log, not mind)
  • Admission caps, depth, spend limits
  • UI
do not build
  • Rewritable step() / scanner / budget
  • L1-only farm (serial kernel, fake parallelism)
  • Empty ABI (you will reinvent rg for six turns)
  • Hot-loop “alive” with no wake policy
  • Moving auth into Python because “the kernel is the OS”
